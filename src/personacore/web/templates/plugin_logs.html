{# plugin_logs.html — what each plugin has printed to its own stderr (PC-279). Two pages, one template: /admin/plugins/logs carries every plugin (the sweep), /admin/plugins//logs carries exactly one (the destination a failing row links to, so getting from a broken plugin to its output is one click). They differ only in how many rows they hold; two templates would be two places for the same four ways of being empty to drift apart. Context: plugins: [{name, transport, text, notes: [], empty_reason, unavailable}], only (name|None), unknown (bool), source_note?, untrusted_note THE TEXT IS UNTRUSTED. It is whatever third-party code wrote to its own stderr, so it is rendered inside 
 as escaped text by Jinja's autoescape
   and is never interpreted as markup (spec 7). Nothing here renders a
   plugin's settings, so no secret name and no secret value can reach this
   page at all — the surest way to keep a value off a screen is for the code
   that would fetch it not to exist. #}
