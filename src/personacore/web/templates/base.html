Context: nav_active (str), health_state ('ok'|'degraded'), security_alert (bool), is_admin (bool), nav_collapsed (bool), here (str — where a toggle comes back to) COLLAPSING. `nav_collapsed` comes from this person's own preference, read by `_shell` before the page is rendered, so the narrow menu is in the markup the browser receives. That is the whole point of doing it server-side: a menu restored by a script paints wide and then snaps shut on every navigation, and this surface navigates by `hx-boost` constantly. Collapsed, the menu is icons alone. The names are gone from the markup rather than hidden with CSS, so every item carries `aria-label` and `title` instead — an icon with no name is unusable with a screen reader and unguessable with a mouse. Two things are deliberately NOT in the collapsed menu: the sub-items (Voices, Recognisers, the Security group's children) and Sign out. Neither has an icon, and inventing one for each would be a worse answer than one click on the toggle. The Security group keeps its shield and its warning dot and expands the menu when pressed, so the dot is never a light nobody can follow. #} {% block title %}PersonaCore admin{% endblock %} {% from "_controls.html" import icon %} {# An icon-only link has no text to read, so it says its name in the two places that are left.
