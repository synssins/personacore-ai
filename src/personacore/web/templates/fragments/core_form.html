{# The Wyoming server — [wyoming] in core.toml. Home Assistant connects to us and we answer as its speech-to-text and text-to-speech. The security sentence is not decoration and is not a hedge: the protocol carries no credential of any kind, so the switch cannot express what turning it on means. Home Assistant (Wyoming)

Lets Home Assistant use this core as its speech-to-text and text-to-speech. The port has no sign-in, no permissions and no encryption, so anything that can reach it can transcribe through this core and make it speak.
