{# THIS PERSONA'S MODEL (ADR-0036). Two radios: the system's connection, or one of its own. The boxes are always in the markup and always submitted — the radio is what the server reads — so the reveal is one stylesheet rule (.reveal-when-chosen) and nothing else. With no CSS at all the boxes are simply visible, which is a form that still works; markup that hid them would be a form whose fields nothing can reach. Choosing the system default REMOVES the section from persona.toml rather than copying today's values into it. Absence is the only thing that means "follow the system", so a persona that spelled the default out would stay on those values when the Models screen moves — which is exactly what pinning is for, and exactly what must not happen to somebody who never asked for it. The API key box is the same one the Models screen has (see fragments/connection_key.html). It is write-only: a typed key goes into the secret store and persona.toml goes on holding only the NAME, and a stored key is never rendered back to this page. An empty box leaves an existing key alone — removing one has its own control. #}
